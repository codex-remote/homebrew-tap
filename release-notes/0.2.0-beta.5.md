# Codex Remote 0.2.0-beta.5

Codex Remote `0.2.0-beta.5` is an unsigned, unnotarized Apple Silicon Beta.
It improves pairing QR readability for ordinary iPhone cameras while retaining
the Runtime restart and native WebSocket compatibility fixes from Beta 4.

## Fixed

- The default terminal QR renderer now uses large square full-block cells and
  a stable quiet zone, removing dependence on terminal font metrics.
- `compact` and `small` QR renderers remain available as explicit space-saving
  options.

## Security and licensing

- Runtime source and new artifacts are licensed under Apache License 2.0.
- This Beta is not signed with Developer ID and is not notarized by Apple.
- The already published Beta 1 through Beta 4 archives retain their historical
  licenses and are not rewritten by this release.

## Compatibility

- macOS Apple Silicon only.
- Codex CLI `0.148.0` or later; tested with `codex-cli 0.154.0-alpha.6.2`.
- iPhone Safari on the same trusted local network.

SHA256 is published as a separate release asset alongside the archive and
manifest.
