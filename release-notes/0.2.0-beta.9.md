# Codex Remote 0.2.0-beta.9

Codex Remote `0.2.0-beta.9` is an unsigned, unnotarized Apple Silicon Beta.
It restores terminal-first pairing output for the main Runtime commands.

## Fixed

- Bare `codex-remote pair` now prints the terminal QR and the copyable
  authenticated one-time pairing URL by default.
- `codex-remote start` and `codex-remote restart` emit the same terminal QR and
  URL after service readiness completes.
- Explicit `--terminal=false --output PATH` remains available for the compact
  pure black/white PNG path introduced in Beta 8.

The terminal renderer uses complete ANSI background cells and the
ZXing-compatible high-redundancy matrix, so the three finder patterns remain
closed. The generated matrix was reconstructed and successfully decoded with
OpenCV before publication.

## Compatibility

- macOS Apple Silicon only.
- Codex CLI `0.148.0` or later; tested with `codex-cli 0.154.0-alpha.6.2`.
- iPhone Safari on the same trusted local network.

SHA256 is published as a separate release asset alongside the archive and
manifest.
