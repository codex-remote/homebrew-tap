# Codex Remote 0.2.0-beta.10

Codex Remote `0.2.0-beta.10` is an unsigned, unnotarized Apple Silicon Beta.
It polishes the terminal presentation shared by `pair`, `start`, and
`restart`.

## Changed

- Pairing output now has distinct colored sections for the title, expiry,
  security notice, copyable URL, QR area, and PNG path.
- URL content is emitted as plain text so users can copy the authenticated link
  without terminal color sequences.
- `NO_COLOR` and redirected output remain stable line-oriented text.
- The QR remains isolated below its own label and blank line, preserving the
  quiet zone and the closed finder-pattern geometry.

## Security and licensing

- Runtime source and this artifact are licensed under Apache License 2.0.
- This Beta is not signed with Developer ID and is not notarized by Apple.
- Previously published Beta archives and tags remain immutable and retain their
  published licenses.

## Compatibility

- macOS Apple Silicon only.
- Codex CLI `0.148.0` or later; tested with `codex-cli 0.154.0-alpha.6.2`.
- iPhone Safari on the same trusted local network.

SHA256 is published as a separate release asset alongside the archive and
manifest.
