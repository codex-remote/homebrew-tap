# Codex Remote 0.2.0-beta.1

> [!CAUTION]
> Superseded by [0.2.0-beta.2](https://github.com/codex-remote/homebrew-tap/releases/tag/v0.2.0-beta.2). This version cannot start Valkey from the default macOS `Application Support` state path. Upgrade before running Setup.

The first public Beta for Apple Silicon Macs.

> [!WARNING]
> This proprietary Beta is not signed with Apple Developer ID and is not
> notarized by Apple. It is intended for testing, carries no production support
> commitment, and may be blocked by some macOS or managed-device security
> policies. Do not disable Gatekeeper globally.

## Highlights

- Use iPhone Safari as a remote workbench for Codex running on your Mac.
- Browse local projects and Codex sessions over the same local network.
- Send tasks, follow live status and execution activity, and read results.
- Pair by QR code, refresh a session, log out, and revoke access from the Mac.
- Keep project files and Codex execution on the Mac.
- Install isolated PostgreSQL and bundled Valkey state without modifying an
  existing PostgreSQL, Redis, or Valkey installation.

## Requirements

- Apple Silicon Mac.
- Codex installed and signed in on the Mac.
- iPhone Safari and Mac connected to the same local network.
- One Safari tab per paired device for this Beta.

## Install

```bash
brew install codex-remote/tap/codex-remote
codex-remote setup --workspace-root ~/work
codex-remote pair
```

## Known limitations

- Unsigned and not Apple notarized.
- Local-network access only; no public TLS endpoint.
- Concurrent refreshes from multiple Safari tabs can trigger replay protection
  and revoke the session.
- Only Apple Silicon is supported.
