# Codex Remote 0.2.0-beta.4

Codex Remote `0.2.0-beta.4` is an unsigned, unnotarized Apple Silicon Beta.
It includes the source-worktree/runtime restart handoff fix and preserves the
existing Runtime data directory and paired-device state during upgrade.

## Fixed

- `codex-remote restart` waits for the old Supervisor process tree and all
  persisted Runtime ports to exit before starting the replacement.
- Failed startup rollback uses the same bounded shutdown barrier and reports
  exact remaining PIDs or ports when the barrier expires.
- Native iPhone and `relayctl` WebSocket project/turn traffic remains routed to
  the requesting App while Runtime HTTP-created Runs are persisted separately.

## Security and licensing

- Runtime source and new artifacts are licensed under Apache License 2.0.
- This Beta is not signed with Developer ID and is not notarized by Apple.
- The already published Beta 1 through Beta 3 archives retain their historical
  license and are not rewritten by this release.

## Compatibility

- macOS Apple Silicon only.
- Codex CLI `0.148.0` or later; tested with `codex-cli 0.154.0-alpha.6.2`.
- iPhone Safari on the same trusted local network.
