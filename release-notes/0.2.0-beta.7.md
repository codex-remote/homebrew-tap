# Codex Remote 0.2.0-beta.7

Codex Remote `0.2.0-beta.7` is an unsigned, unnotarized Apple Silicon Beta.
It fixes the finder-pattern alignment in the terminal pairing QR renderer.

## Fixed

- The camera renderer now uses the encoder's standard four-module quiet zone
  without adding a one-module offset.
- The upper-left and upper-right finder-pattern borders stay joined instead of
  rendering as a detached black row above the QR code in Terminal.app.
- The default output is roughly 45 x 23 terminal cells while retaining pure
  black/white ANSI backgrounds and the explicit `large`, `compact`, and `small`
  renderer overrides.

The actual ANSI output was reconstructed as a pure black/white bitmap. The
finder corner alignment was verified and the result was successfully detected
and decoded with OpenCV before publication.

## Compatibility

- macOS Apple Silicon only.
- Codex CLI `0.148.0` or later; tested with `codex-cli 0.154.0-alpha.6.2`.
- iPhone Safari on the same trusted local network.

SHA256 is published as a separate release asset alongside the archive and
manifest.
