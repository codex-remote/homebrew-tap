# Codex Remote 0.2.0-beta.8

Codex Remote `0.2.0-beta.8` is an unsigned, unnotarized Apple Silicon Beta.
It changes the default `codex-remote pair` workflow to open a compact QR image
designed for iPhone-camera scanning.

## Fixed

- Bare `codex-remote pair` now generates a private PNG and opens it with the
  macOS image viewer. Explicit `--terminal` and `--output` options retain their
  direct control over the display path.
- Replace the old QR encoder with ZXing-compatible `gozxing v0.1.1`, high
  error correction, and an explicit four-module quiet zone.
- The default camera terminal renderer uses complete ANSI background cells,
  not half-block glyphs, so the left-top, right-top, and left-bottom finder
  patterns stay closed.
- PNG output uses 5px integer modules without interpolation. The current
  pairing payload produces an approximately 285 x 285 pure black/white image.

The generated PNG and reconstructed terminal matrix were successfully detected
and decoded with OpenCV before publication.

## Compatibility

- macOS Apple Silicon only.
- Codex CLI `0.148.0` or later; tested with `codex-cli 0.154.0-alpha.6.2`.
- iPhone Safari on the same trusted local network.

SHA256 is published as a separate release asset alongside the archive and
manifest.
