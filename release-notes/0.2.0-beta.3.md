# Codex Remote 0.2.0-beta.3

This Beta replaces five duplicate-looking macOS Login Items with one Runtime
Supervisor.

> [!WARNING]
> This proprietary Beta is not signed with Apple Developer ID and is not
> notarized by Apple. It is intended for testing and carries no production
> support commitment. Do not disable Gatekeeper globally.

## Changed

- Register only `com.codex-remote.runtime` with launchd.
- Supervise PostgreSQL, Valkey, Relay, Mac Agent, and Gateway as child processes
  in dependency order.
- Keep separate stdout and stderr logs for every managed service.
- Stop all managed children when one exits unexpectedly, then let launchd
  restart the single Supervisor.
- During repair, unload and remove only the five exact legacy LaunchAgent
  labels and plist files.
- Update `status`, Doctor, migration, rollback, stop, restart, and uninstall for
  the single-Supervisor layout.

## Install

```bash
brew install codex-remote/tap/codex-remote
codex-remote setup --workspace-root ~/work
codex-remote pair
```

## Upgrade from an earlier Beta

Run from an external Terminal:

```bash
brew update
brew upgrade codex-remote
codex-remote setup --repair
codex-remote doctor --json
```

Repair preserves configuration, database data, Keychain credentials, ports,
and workspace roots while migrating the Login Items.

## Known limitations

- Unsigned and not Apple notarized.
- Local-network access only; no public TLS endpoint.
- Concurrent refreshes from multiple Safari tabs can trigger replay protection
  and revoke the session.
- Only Apple Silicon is supported.
